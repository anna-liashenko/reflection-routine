# reflection-routine

Morning and evening reflection questions, delivered on Telegram or in chat, run locally or as a cloud routine. Personal reflections live in a separate data folder (`$REFLECTIONS_DIR` or `./data`), never in this repo. See README.md.

- First time here, or the person asks to set it up: follow `.claude/skills/reflection-setup/SKILL.md`. It asks the choices; never ask for a bot token in chat.
- To run one pass by hand: `.claude/skills/reflection-run/SKILL.md` with `morning` or `evening`.
- Never commit `.telegram-config.json`, tokens, or anything from the data folder into this repo.
